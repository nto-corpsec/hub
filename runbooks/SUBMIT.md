# Runbook: сдача задания

## Перед отправкой

- [ ] Ответ воспроизведён вторым человеком
- [ ] Формат соответствует требованию (регистр, пробелы, кодировка)
- [ ] Нет дублирующей отправки другим участником
- [ ] Есть скриншот/лог подтверждения
- [ ] Запись в `ops/answers` и `ops/notes/timeline.md` сделана

## Во время

- Один канал, один отправитель.
- При ошибке платформы — фиксируем текст ошибки, не паникуем, не дублируем вслепую.
- Если ответ неверный — статус в issue, разбор, новая гипотеза. Не «дожимаем» наугад.

## После

Комментарий в issue задачи: `submitted`, время, результат, ссылка на evidence.
