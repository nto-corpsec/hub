# Доска

Один org-level Project v2 «NTO 2026 — Board»: задачи, роли, приоритеты.

| Поле | Значения |
|---|---|
| Status | Backlog, Ready, In progress, Review, Done, Blocked |
| Role | lead, soceng, dfir, netsec, websec, osint |
| Priority | P0, P1, P2, P3 |
| Effort | часы |

Представления: `By role`, `P0/P1`, `My work`.

Как создать и настроить — [docs/PROJECT.md](../docs/PROJECT.md).

Правила: одна карточка = одна issue; `Blocked` ставится сразу; в `In progress` всегда есть assignee.
