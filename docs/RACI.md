# RACI

R — делает, A — отвечает за результат, C — консультирует, I — информируется.

| Активность | Lead | SocEng | DFIR | NetSec | WebSec |
|---|---|---|---|---|---|
| Приоритизация бэклога | A/R | C | C | C | C |
| Разведка инфраструктуры (OSINT) | A/R | C | I | C | I |
| Фишинговый сценарий на стенде | A | R | I | I | I |
| Разбор EVTX/реестра | A | I | R | I | I |
| Восстановление удалённых данных | A | I | R | I | I |
| Анализ pcap | A | I | C | R | I |
| Правила Suricata/Zeek | A | I | C | R | I |
| Поиск и эксплуатация веб-уязвимостей | A | I | I | I | R |
| Ремидиация веб-приложения | A | I | I | C | R |
| Ревью PR в `arsenal` | A | R | R | R | R |
| Ведение `ops` (ответы, флаги) | A/R | C | C | C | C |
| Сдача задания | A/R | C | C | C | C |
| Инфраструктура CI и rulesets | A/R | I | I | I | I |
| Ретро | A/R | C | C | C | C |

Правило: если у задачи два «A» — задача не декомпозирована.
