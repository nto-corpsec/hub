# ADR-0001: GitHub Free + публичные репозитории

- **Статус:** принято
- **Дата:** 2026-10-26
- **Контекст:** организация на 5 человек, этап 17.11–15.12.2026, бюджет ограничен

## Проблема

На GitHub Free возможности защиты веток, rulesets и CODEOWNERS доступны **только в
публичных** репозиториях. В приватных их нет: контроль остаётся на уровне договорённостей.

Варианты:

1. **Team, ~$20/мес** — приватность + полный набор защит.
2. **Free + публичные репозитории** — полный набор защит бесплатно, но всё видно.
3. **Free + приватные репозитории** — приватность без технических гарантий.

## Решение

Выбран вариант 2: GitHub Free для организаций, инженерные репозитории публичные.

## Последствия

**Положительные:**

- Branch protection, rulesets, CODEOWNERS, обязательные ревью — работают.
- Неограниченные минуты Actions на публичных репозиториях.
- Бесплатные CodeQL, secret scanning и push protection для публичных репозиториев.
- Нет ежемесячного платежа.

**Отрицательные:**

- Решения, флаги и сырые артефакты видны конкурентам — их нельзя коммитить в публичные репо.
- Любая ошибка с секретом необратима: форки и кэши сохраняют данные.
- Приватный `ops` остаётся без технической защиты (только процесс и ревью лида).

**Компенсация:**

- Введён отдельный приватный репозиторий `ops` для ответов и доказательств.
- gitleaks + semgrep + push protection на каждом PR.
- Чек-лист «нет флагов и секретов» в PR-шаблоне и issue-формах.
- Runbook `SECRET-LEAK` отработан на учениях до этапа.

## Пересмотр

Если появится бюджет на Team — перевести `ops` и `arsenal` в приватные и включить rulesets.
